# PAWN SHIFT Korean Font Fallback

Runtime Korean TMP font fallback plugin for **PAWN SHIFT Demo**.

Target detected from the user's game files:

- Unity `6000.3.10f1`
- IL2CPP
- TextMesh Pro
- BepInEx 6 IL2CPP

This repository does **not** contain the game, game DLLs, or a font file.

## Build

Open **Actions** → **Build PAWN SHIFT Korean Font Plugin** → **Run workflow**.

A successful run creates:

- `PAWNShift.KoreanFontFallback.dll`
- `PAWN_SHIFT_KoreanFontFallback.zip`

## Install

See `INSTALL_README.txt`.

The plugin does not replace or edit `resources.assets`.
